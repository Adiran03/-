CONFUSION MATRIX
1. Истинное обнаружение (TP) Взлом: ДА | Сигнал: ДА

Датчик сработал на реального злоумышленника. Группа немедленного реагирования задерживает нарушителя на периметре.

Вероятность: 0.02 × P_det (до 1900 случаев / 100k ч)
2. Пропуск цели (FN) Взлом: ДА | Сигнал: НЕТ

Катастрофическая ошибка защиты. Преступник проник на охраняемую территорию, датчик промолчал. Хищение данных или имущества.

Вероятность: 0.02 × (1 - P_det) (до 600 пропусков!)
3. Ложная тревога (FP) Взлом: НЕТ | Сигнал: ДА

Помехи, ветер, птицы или тепловые всплески. Холостой выезд охраны. Ведет к истощению бюджета и синдрому «мальчика и волков».

Вероятность: 0.98 × P_fls (до 4900 фейков!)
4. Нормальный покой (TN) Взлом: НЕТ | Сигнал: НЕТ

Штатное фоновое состояние. Нарушений нет, сенсор сохраняет пассивность. Подавляющее большинство времени системы.

Вероятность: 0.98 × (1 - P_fls) (~93 100 - 97 510 ч)

Теоретический аппарат Байеса

Апостериорная вероятность того, что сработавший сигнал вызван реальным преступником:

P(H₁|A) = [ P(H₁) · P(A|H₁) ] / P(A)

P(A) = 0.02 · P_det + 0.98 · P_fls

Precision = (0.02 · P_det) / (0.02 · P_det + 0.98 · P_fls)

Вывод: если повысить P_det с 70% до 95%, но допустить рост P_fls до 5%, надежность падает в 2.8 раза!

Консольная программа C++20 (ГОСТ) 

#include <iostream>
#include <iomanip>
#include <vector>
#include <random>

int main() {
    std::mt19937_64 rng(1337);
    std::uniform_real_distribution<double> dist(0.0, 1.0);
    const long long N = 100000;
    const double P_INTR = 0.02;

    std::vector<double> p_dets = {0.70, 0.85, 0.95};
    std::vector<double> p_flss = {0.005, 0.020, 0.050};

    for (double p_det : p_dets) {
        for (double p_fls : p_flss) {
            long long tp = 0, fn = 0, fp = 0, tn = 0;
            for (long long i = 0; i < N; ++i) {
                if (dist(rng) < P_INTR) {
                    (dist(rng) < p_det) ? tp++ : fn++;
                } else {
                    (dist(rng) < p_fls) ? fp++ : tn++;
                }
            }
            double prec = (tp + fp > 0) ? (double)tp / (tp + fp) * 100.0 : 0.0;
            std::cout << "P_det: " << p_det << " P_fls: " << p_fls 
                      << " TP: " << tp << " FP: " << fp << " Prec: " << prec << "%\n";
        }
    }
    return 0;
}
